# Sims Tan

Prototipo inicial de simulador de vida para PC y móvil.

## Incluido en la primera maqueta

- Menú principal.
- Creación de personaje responsive.
- Habitación isométrica interactiva.
- Movimiento con teclado y selección táctil/clic.
- Muebles con menú contextual.
- HUD de necesidades, hora y dinero.
- Pantalla inicial de multijugador.
- Arquitectura de interfaz compatible con escritorio y móvil.

## Ejecutar

Abrir `index.html` en un navegador moderno. En esta fase de maqueta el proyecto se ha cargado al repositorio antes de cualquier validación, conforme al flujo de desarrollo establecido.
